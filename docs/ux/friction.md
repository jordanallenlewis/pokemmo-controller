# Friction list: what a new player hits today

Read from the current README and installers. Each row says what the player
meets and which milestone removes it.

| # | Friction | Fixed in |
|---|---|---|
| 1 | Must open PowerShell or Terminal and paste a line. Many players do not know what that is, and some will not paste a line from the internet. | A1 |
| 2 | On Windows, the paste-and-run line can be blocked by policy or look suspicious to antivirus. | A1 |
| 3 | PokeMMO has to be closed first, and the player has to know that. | A1 (app closes it safely) |
| 4 | Steam is closed and reopened by the installer. The player is not told why until it happens. | A1 |
| 5 | No picture of the result. The player cannot tell whether the pad works until they are inside the game. | A2 |
| 6 | Remapping means editing a layout or using a page that opens in a browser tab, not an app. | A2, A3 |
| 7 | The remap page cannot show live presses, so a wrong pad or a dead button is found in game. | A2 |
| 8 | A second pad or a PlayStation or Switch pad can be mistaken for the first. | A2 |
| 9 | Uninstall and update mean running another command. | A3 |
| 10 | Windows SmartScreen and macOS Gatekeeper warn about unsigned programs. | A5 (needs Jordan's decision) |
| 11 | Steam Deck: Desktop Mode, a terminal and a browser tab. | A4 |
| 12 | The game rewriting its settings can undo the binds with no sign. | H2 (already planned) |

Not friction we can remove: the player must still own PokeMMO and Steam, and
Steam Deck Game Mode stays unverified until a person tests it.
