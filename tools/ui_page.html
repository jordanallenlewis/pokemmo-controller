PokeMMO Controller

Your controller

Click a button to change what it does. Each button does one thing: if you give it an action another button has, the two swap.

Press a button on your controller and it is picked here.

Right-stick wheel

Tilt the right stick toward a slice and let go: it presses that slice's key once. The top slice does nothing on purpose, so letting go while pointing up sends no key.

Setup

What PokeMMO needs to find, and what this app keeps true.

    Controller

    Button names follow the controller you pick. One layout fits all three.

    Layout file

    Keep a copy of your layout, or load one a friend sent. A file that breaks the one-button-one-action rule is refused.

    Updates

    When a new version is out, a short note appears at the top with one button to install it. Your layout is kept, and the old version comes back by itself if anything goes wrong.

    About

    PokeMMO Controller is an unofficial, fan-made tool, made by and for PokeMMO players. It is not made, endorsed or supported by the PokeMMO team.

    PokeMMO allows remapping while one input does one thing. Each button holds one action and each wheel slice presses one key when you let go, so this screen cannot set up anything else. It runs on your computer only. The one thing it asks the internet is whether a newer release exists, and that sends nothing about you; you can turn it off under Updates.
