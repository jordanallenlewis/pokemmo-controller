PokeMMO controller layout

Looking for PokeMMO…

PokeMMO allows remapping while one input does one thing. Each input holds one action and each wheel slice presses one key when you let go, so this screen cannot set up anything else.

Buttons

Pick the input for each action. If that input already does something else, the two swap.

Right-stick wheel (Steam)

Tilt the right stick, let go on a slice. Slice 1 is at the top, then clockwise. The picture is a preview.
